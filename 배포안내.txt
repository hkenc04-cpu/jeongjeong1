================================================================
 적정주가 폰 앱 - 무료 클라우드 사이트에 올리는 방법
================================================================
폰 브라우저는 SEC·DART·Yahoo를 직접 부를 수 없어서, 계산을 대신 해 주는 '서버'가 필요합니다.
아래 순서대로 한 가지만 하면 됩니다. 한 번 올리면 주소 하나로 아이폰·안드로이드 어디서든 열립니다.

  방법 1. Render        ← 기본 추천 (카드 등록 없음)
  방법 2. SnapDeploy    (Render가 안 될 때 대안, 카드 등록 없음)
  방법 3. Railway       (대안, 체험 크레딧 방식)
  방법 4. 내 PC를 서버로 (사이트 없이, 집 와이파이/Tailscale)

공통 준비물 3가지(방법 1~3)
  - 비밀번호: 내가 정하는 8자 이상 (APP_PASSWORD). 남이 내 서버를 못 쓰게 하는 열쇠입니다. 길게 정하세요.
  - 이메일: SEC가 요구하는 연락처(SEC_CONTACT). 실제 쓰는 주소.
  - (한국 종목용) DART 인증키 40자리: https://opendart.fss.or.kr 무료 가입 후 발급 (앱 [설정]에서 나중에 넣어도 됨)

※ 사이트 화면 이름과 무료 조건은 바뀔 수 있습니다. 화면이 다르면 그 화면을 알려 주세요.

================================================================
방법 1. Render (기본)
================================================================
무료 조건(제가 확인한 내용): 카드 없이 사용, 15분 안 쓰면 잠들고 다시 열 때 약 1분, 월 750시간, 메모리 512MB.
※ 클라우드 서버 IP는 Yahoo가 시세를 막는 일이 있습니다. 그때는 분석 화면의 [현재가 직접 입력]을 쓰세요.

[1] GitHub에 파일 올리기 (Render는 GitHub에서 파일을 가져갑니다)
   1) https://github.com 무료 가입(이메일 인증).
   2) 오른쪽 위 [+] → New repository → 이름: jeongjeong → Public 선택 → [Create repository]
   3) 만들어진 화면의 "uploading an existing file" 링크 클릭.
   4) zip을 푼 폴더의 모든 파일과 static 폴더를 한꺼번에 끌어다 놓기
      (Dockerfile, render.yaml, requirements.txt, server.py, engine.py, run_pc.py 등 + static 폴더)
      ※ static 폴더는 폴더째 올려야 합니다. 폴더 구조·파일 이름을 바꾸지 마세요.
   5) 아래 [Commit changes].
   (폴더째 끌어다 놓기가 안 되면: 폰이 아닌 PC 크롬/엣지로 하세요.)

[2] Render에서 서버 만들기
   1) https://render.com → [Get Started] → [GitHub로 로그인](Sign in with GitHub) → 저장소 접근 허용.
   2) 화면 위쪽 [+ New] → [Web Service] → 방금 만든 jeongjeong 저장소 선택 → [Connect].
   3) 설정 화면:
        Name: 아무거나(예: jeongjeong)   Region: Singapore(가까움) 권장
        Language(Runtime): Docker     ← 중요
        Instance Type: Free
   4) 같은 화면의 [Environment Variables](환경변수)에 추가:
        APP_PASSWORD = 내 비밀번호     ← 필수. 없으면 앱이 아무 요청도 받지 않습니다
        SEC_CONTACT  = 내 이메일
        DART_KEY     = DART 인증키 40자리 (선택)
   5) [Deploy Web Service]. 빌드가 3~6분 걸립니다("Live"가 되면 완료).
   6) 화면 위쪽의 주소(https://jeongjeong-xxxx.onrender.com)를 폰 브라우저에 입력.

[3] 폰에서 쓰기
   - 비밀번호 입력 → [설정]에서 이메일·DART 키가 들어갔는지 확인(환경변수로 넣었으면 이미 반영).
   - 처음 열 때나 한동안 안 쓴 뒤에는 서버가 깨어나는 1분 정도가 걸립니다.
   - 홈 화면에 추가: 아이폰 Safari 공유 → "홈 화면에 추가" / 안드로이드 Chrome ⋮ → "앱 설치" 또는 "홈 화면에 추가"

[업데이트] 새 zip으로 GitHub 저장소의 파일을 같은 이름으로 다시 올리면 Render가 자동으로 새로 배포합니다.

================================================================
방법 2. SnapDeploy (Render가 안 될 때)
================================================================
무료 조건(검색으로 확인): 카드 없이 사용, 월 100시간, 메모리 512MB, 15분 안 쓰면 잠듦(깨는 데 약 60초). Docker 배포 지원.
 1) 방법 1의 [1] 단계로 GitHub 저장소를 만듭니다(같은 저장소 사용 가능).
 2) https://snapdeploy.dev 가입 → GitHub 연결 → 저장소 선택 → Docker(Dockerfile) 배포.
 3) 환경변수에 APP_PASSWORD(필수), SEC_CONTACT, DART_KEY 등록 → 배포 후 나온 주소를 폰에 입력.
 ※ 이 사이트는 제가 화면까지 확인하지 못했습니다. 메뉴 이름이 다르면 알려 주세요.

================================================================
방법 3. Railway (대안)
================================================================
무료 조건(검색으로 확인): 카드 없이 시작, 첫 30일은 5달러 체험 크레딧, 이후 월 1달러 크레딧(사실상 부족할 수 있음).
 1) https://railway.com 가입(GitHub 연동) → New Project → Deploy from GitHub repo → 저장소 선택(Dockerfile 자동 인식).
 2) Variables에 APP_PASSWORD(필수)·SEC_CONTACT·DART_KEY 추가.
 3) Settings → Networking → Generate Domain 으로 주소를 만들어 폰에 입력.
 ※ 크레딧이 떨어지면 멈춥니다. 오래 쓰려면 방법 1이 낫습니다.

================================================================
방법 4. 내 PC를 서버로 (사이트 없이)
================================================================
 - 집 와이파이: 폴더의 실행하기_PC서버.bat 더블클릭 → 비밀번호 설정 → 검은 창에 나온 주소(http://192.168.….:7860)를
   같은 와이파이의 폰에 입력. Python이 필요합니다(https://www.python.org/downloads/ , "Add python.exe to PATH" 체크).
   Windows 방화벽 창이 뜨면 [액세스 허용]. PC가 켜져 있고 검은 창이 열려 있어야 합니다.
 - 집 밖에서: PC와 폰에 Tailscale(https://tailscale.com, 개인 무료)을 설치해 같은 계정으로 로그인하면
   폰에서 http://(PC의 Tailscale 주소 100.x.x.x):7860 으로 접속됩니다. 인터넷에 공개되지 않아 안전합니다.
 - 장점: 가입·배포 없음, 집 인터넷 주소라 Yahoo가 막을 가능성이 낮고 받은 자료가 PC에 남아 두 번째부터 빠릅니다.

================================================================
쓰지 말 것(이 앱에는 안 맞음)
================================================================
 - PythonAnywhere 무료: 외부 접속이 허용 목록 사이트로만 제한되어 SEC·DART·Yahoo에 못 닿을 가능성이 큼
 - Vercel / Netlify / Cloudflare Pages: 이 앱 같은 서버(Flask)를 그대로 돌릴 수 없음
 - Fly.io / Google Cloud Run / Koyeb: 카드 등록이 필요
 - Hugging Face: 이번 안내에서는 제외했습니다(접속이 안 되는 환경이 있어서)

================================================================
사용 팁·한계
================================================================
 - 처음 보는 미국 종목 10~40초, 한국 종목 1~3분, 사업보고서 점검 1~3분. 클라우드는 서버가 다시 시작되면 받아 둔 자료가 지워져 다시 느려집니다.
 - Yahoo가 시세를 안 주면 분석 화면의 [현재가 직접 입력]에 가격을 넣어 다시 계산하세요.
 - SEC가 "요청 과다"로 막으면 30분~1시간 뒤 다시 시도하세요.
 - 관심종목·노트는 폰 브라우저에 저장됩니다. 설정 탭의 [백업·복원]으로 가끔 저장해 두세요.
 - 참고용이며 투자 권유가 아닙니다.
